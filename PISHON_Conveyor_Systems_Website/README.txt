PISHON CONVEYOR SYSTEMS — Frontend

Files:
- index.html
- style.css
- script.js

How to run:
1. Put all three files in the same folder.
2. Open index.html in a browser, or use VS Code + Live Server.
3. For the contact form, replace YOUR_WEB3FORMS_ACCESS_KEY in index.html with your Web3Forms access key.

Features:
- Glassmorphism sticky navigation
- Animated conveyor-style preloader
- Responsive split hero
- CSS machinery illustration (no external image dependency)
- Infinite product conveyor animation with hover pause
- Native HTML <dialog> product specification modals
- Responsive promise cards
- Web3Forms-ready contact form
- Responsive mobile navigation
- SVG wave background
